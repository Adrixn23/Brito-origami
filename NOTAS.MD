# NOTAS - Guía Vaso de Origami

Dirección visual: Estilo mobile-first dinámico y divertido para adultos mayores, con botones táctiles vivaces y feedback positivo.
Colores: Papel verde claro (#6ee7b7) sobre fondo claro (#f8fafc) con acentos de celebración y alto contraste.
Razón: Genera entusiasmo mediante microinteracciones y celebración de logros, manteniendo un flujo 100% offline.

Decisiones técnicas: Carrusel dinámico en JS nativo con animación de confeti nativa en la pantalla final.
Ilustraciones: Diagramas vectoriales SVG puros con flechas de acción claras creados con soporte de IA.
Lo que no dio tiempo: Sonidos sintéticos Web Audio API (se priorizó la experiencia puramente visual para evitar molestias).
Tiempo total: 45 minutos (diseño visual, microinteracciones con IA y prueba física de origami).
